# qemu-jornada720

Цель проекта: научиться запускать **Windows CE для HP Jornada 720** в **QEMU**.

## Статус

Планирование. Работающего кода пока нет. См. `docs/research.md` (что уже известно)
и `docs/plan.md` (по каким шагам двигаемся).

## Коротко про задачу

- HP Jornada 720/728 — КПК на базе **Intel/StrongARM SA-1110** (ARM, 206 МГц).
- В апстриме QEMU готовой машины (`-M jornada720`) нет.
- Но модель самого чипа SA-1110 в QEMU уже есть (`hw/arm/strongarm.c`),
  её использует существующая машина `collie` (Sharp Zaurus SL-5500, тоже SA-1110).
- Значит, не хватает только **платы** — файла вида `hw/arm/jornada720.c`,
  описывающего то, что вокруг чипа: LCD-панель, флеш, клавиатуру/тачскрин, IrDA и т.д.
- Похожая работа уже проделана для **MAME** (`jornada.cpp` поверх `sa1110.cpp`,
  автор — Ryan Holtz): там Windows CE грузится до узнаваемого состояния,
  но всё ещё очень медленно и местами нерабочее (тачскрин, скорость).

Итоговая конечная цель — своя machine-модель для QEMU, по аналогии с тем,
что в MAME уже есть для SA-1110, но использующая существующий код QEMU
(`strongarm.c`, `collie.c` как шаблон) вместо написания CPU-эмуляции с нуля.

## Структура репозитория

- `docs/research.md` — собранные факты, ссылки, характеристики железа.
- `docs/plan.md` — пошаговый план работ.
- (дальше) `src/` — код machine-файла для QEMU, когда дойдём до реализации.
